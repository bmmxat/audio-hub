# Audio Hub v0.1

Windows 专用轻量级音频管理工具，类似 VoiceMeeter 简化版，面向普通游戏玩家。

## 功能

- 🎚️ **应用音量控制** — 滑块 + 静音，实时调节每个应用的音量
- 📋 **音频设备管理** — 枚举所有输出/输入设备，右侧抽屉展示
- 👁️ **应用隐藏** — 隐藏不常用的应用，列表更简洁
- 💾 **Profile 配置** — 一键保存/恢复应用音量快照（游戏模式、工作模式…）
- 🌙 **浅色/暗色双主题** — 自动记住偏好

## 技术栈

- Rust + Tauri 2 + Windows WASAPI
- 前端：纯 HTML/CSS/JS（零构建工具）
- 仅支持 Windows

## 开发

```bash
npm install
npx tauri dev
```

## 已知限制

- 默认设备切换在 Win11 22H2+ 上被系统锁定，点击切换会打开 Windows 声音设置面板
- 应用音量调节基于 PID 匹配，应用重启后 PID 变化，Profile 应用依赖进程名智能匹配
